# Sweep 1.1.0

Security, accessibility and packaging pass — every fix comes from an adversarial
review of the 1.0.0 codebase.

## Security

- Symlinked scan roots are now fail-closed: a `~/.Trash` that is a symbolic link
  can no longer turn "Empty Trash" into permanent deletions outside the Trash.
- Protected-path checks are case-insensitive (APFS), so `~/library` can no longer
  bypass them, on both the literal and resolved paths.
- Sensitive bundles (`.app`, photo libraries, virtual machines, sparse images)
  are marked protected and cannot be selected, including inside the Trash.
- Custom large-file roots are validated against an allowlist: `/`, `/Users`,
  `/Volumes`, `/private` and system folders are refused before scanning.

## Reliability

- Unreadable locations no longer look like "nothing to clean": the scan reports
  failed roots and skipped folders, and the UI shows a partial-scan banner with
  a Full Disk Access shortcut when permissions are the cause.
- Cleaning now runs off the main thread with a per-category state, a Cancel
  action, and double-clean protection.
- "Freed" bytes are measured just before deletion instead of assumed.

## Accessibility and UX

- VoiceOver: rows expose their selection state, safety status, size and date,
  with Reveal/Copy actions.
- Return (↵) no longer triggers the destructive "Empty Trash" button.
- Caution colors meet contrast requirements in light mode; animations respect
  Reduce Motion.
- "Select All" only checks safe items and never clears manual selections of
  flagged items.

## Packaging

- `make dmg` produces a drag-to-Applications disk image next to the zip; the
  release workflow uploads both with SHA-256 checksums.

## Install

1. Download `Sweep-1.1.0.dmg`
2. Open it and drag **Sweep** into **Applications**
