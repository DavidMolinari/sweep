# Sweep 1.0.0

First public release — a native macOS disk cleaner that never deletes anything permanently by accident.

## Highlights

- **Caches, logs and Trash** — review `~/Library/Caches`, `~/Library/Logs` and `~/.Trash` with real allocated sizes.
- **Developer caches** — Xcode DerivedData and DeviceSupport, CoreSimulator, Homebrew, npm/yarn/pnpm, Gradle, Cargo, pip, go-build, CocoaPods, SwiftPM, Hugging Face and more.
- **Large files** — scan your user folders for big or old files with a configurable threshold and a 6-month filter.
- **Safety by design** — everything is moved to the Trash and stays recoverable. Protected locations, project subtrees and sensitive bundles (`.app`, photo libraries, virtual machines) are never offered for deletion.
- **Flagged items** — caches of running apps, archives, disk images and databases are unchecked by default with a visible reason.
- **Native SwiftUI app** — dark and light mode, keyboard shortcuts, accessibility, localized in English, French, German and Spanish.
- **Headless mode** — `Sweep --scan caches logs` and `Sweep --selftest` for scripting and CI.

## Requirements

- macOS 14 or later.
- The app is signed ad-hoc (not notarized yet): on first launch, right-click the app and choose **Open**.

## Install

1. Download `Sweep-1.0.0.dmg`
2. Open it and drag **Sweep** into **Applications**
