# Sweep — Brand & Design Guidelines

Single source of truth for the visual identity of Sweep, a native macOS disk cleaner.
Color tokens live in `Sources/Sweep/Views/BrandPalette.swift`; this document references
them by name. The app icon is generated by `Support/Branding/generate-icon.swift`.

---

## 1. Brand at a glance

Sweep is a calm, premium utility: quiet surfaces, one clear accent, no chrome noise.
The identity rests on three ideas:

- **Emptying** — a thick ring with a gap: a disk being cleared.
- **Motion** — the ring tapers into a trailing tip, like a wiper stroke.
- **Clean result** — a four-point sparkle where the material has been swept away.

Voice: short, factual, reassuring. The safety model (everything recoverable except the
explicit "empty trash") is part of the brand and must never be dramatized.

## 2. Logo

### 2.1 Construction

The mark is drawn with cubic Béziers on a 1024×1024 grid (y-up Core Graphics space):

| Element | Value |
| --- | --- |
| Canvas | 1024 × 1024 |
| Body | 824 × 824, centered → 100 px transparent margin on every side |
| Body shape | superellipse (continuous corner), exponent 5.0 |
| Ring centerline | radius 242, centered at (512, 512) |
| Ring thickness | 132 at full width, tapering to 18 % at the trailing tip |
| Sweep span | 258°, gap of 102° centered at 45° (upper right) |
| Sparkle | 4-point star, radius 108, center at 254 from icon center, angle 45° |

Layer order: drop shadow → base gradient → soft radial halo → ring + sparkle (with
shadow and vertical white→ice gradient) → rim light. Nothing else.

### 2.2 Color application on the icon

- Base gradient: `#0C1134` → `#1E2280` → `#4634CE` → `#7F52FF` (top-left to bottom-right).
- Motif: white `#FFFFFF` → `#DFE8FF`; sparkle glow `#A9C4FF` at low opacity.
- Ground shadow: `#04061A` at ~46 %, y-offset −14, blur 38.
- Top rim light: white at 34 % fading over ~320 px; bottom rim shade: `#03040F` at 30 %.

### 2.3 Assets

```
Support/Branding/
  generate-icon.swift   # swift Support/Branding/generate-icon.swift
  icon-16.png … icon-1024.png
  icon-16@2x.png … icon-512@2x.png
  AppIcon.icns          # iconutil -c icns, bundled as AppIcon.icns
```

### 2.4 Clear space and minimum sizes

- Clear space: keep at least **25 % of the body width** (≈ 206 px at 1024) free of any
  other element on all sides.
- Minimum sizes: **16 px** for menu bar / Finder lists, **32 px** for toolbar use.
  Below 16 px use no icon at all.
- Do not place the icon on a shape or plate: the squircle and its shadow are part of the
  artwork and are already baked in.

### 2.5 Logo do / don't

| Do | Don't |
| --- | --- |
| Use `AppIcon.icns` as produced by the script | Recolour, rotate, skew, or outline the mark |
| Keep the transparent margin | Crop into the squircle or add another container |
| Scale proportionally | Rebuild the ring/sparkle from scratch with other proportions |
| Use the sparkle alone only as a decorative glyph (SF Symbol `sparkles`) | Use the ring/sparkle as a standalone trademark in a different style |

## 4. Typography

System font only (SF Pro through the macOS text styles). No custom typefaces.

| Usage | Style |
| --- | --- |
| Sheet / empty-state titles | `.title3`, semibold |
| Body copy, explanations | `.callout`, regular, secondary color |
| Labels, failure lines | `.caption`, regular or semibold |
| Byte counts, sizes, counters | `.callout`/`.title3` with `.monospacedDigit()` |

Rules:
- Numbers that live-update must use `.monospacedDigit()`.
- Never set text below `.caption`. Never use all-caps for anything but acronyms.
- Uppercase is not part of the brand voice; sentence case everywhere.

## 5. Composition principles

- **One accent per surface**: a category color exists to identify a category, not to
  decorate. A screen shows at most one category gradient at full strength.
- **Glass is a surface, not a texture**: `glassSurface` is reserved for panels that float
  over content (sheets, consoles). Content areas stay plain.
- **Tiles are small**: `GradientIconTile` is capped at 68 pt in practice; use
  `IconMedallion` when the state should dominate (scanning, success, failure).
- **Motion is functional**: the only ambient animation is `SpinningRing`. Everything else
  responds to user action and stays under 0.25 s.
- **Danger is explicit**: destructive affordances use `danger`/`warning` tokens and are
  never pre-selected. Default selection is always the safe subset.

## 6. Iconography inside the app

- UI glyphs are SF Symbols (system license — UI only, never part of the logo).
- Glyphs on gradient tiles are white with a subtle black drop shadow
  (`Elevation.tileSymbol*`); this is what keeps them legible on the lightest stops.
- Symbol size on a tile is 46 % of the tile edge.

## 7. Accessibility

### 7.1 Contrast (WCAG 2.1)

Measured values; white text/glyphs on the gradient bottoms and brand colors:

| Pair | Ratio | Verdict |
| --- | --- | --- |
| White on `brand.primary` `#1F6BFA` | 4.62:1 | AA (large/graphic) |
| White on `brand.violet` `#7F52FF` | 4.61:1 | AA (large/graphic) |
| White on `brand.indigo` `#4634CE` | 7.95:1 | AAA |
| White on `brand.midnight` `#0C1134` | 18.3:1 | AAA |
| White on caches bottom `#1F6BFA` | 4.62:1 | AA (large/graphic) |
| White on trash bottom `#DE2E47` | 4.58:1 | AA (large/graphic) |
| White on developer bottom `#664FF0` | 5.33:1 | AA |
| White on logs bottom `#59667F` | 5.78:1 | AA |
| White on large-files bottom `#F5701A` | 2.91:1 | Graphic only, never text |
| White on lightest stops (tops) | 1.7–2.6:1 | Graphic only, never text |

Rules:
- **Never place text on a category gradient.** Text always sits on the window/material
  background, where the system colors apply.
- Glyphs on tiles are decorative: every tile is paired with a visible text label.
- On the lightest stops (`FFBD52`, `5CBDFF`, `B88FFF`) the white glyph relies on its
  shadow; do not remove `Elevation.tileSymbolShadowOpacity`.
- Secondary text (`Color.secondary`): 5.07:1 on light windows, 6.48:1 on dark. Keep body
  text at `.callout` or larger.
- Never encode category or safety state by color alone: pair it with a symbol and a label
  (the yellow "caution" state already does this).

### 7.2 Other

- Full keyboard access: every destructive action has an explicit button; `⌘R` / `⇧⌘R`
  trigger scans.
- Respect Reduce Motion: `SpinningRing` is the only continuous animation and should be
  replaced by a static track when `accessibilityReduceMotion` is on.
- Localized strings never truncate the layout at `.caption`; test EN/FR/DE/ES.
